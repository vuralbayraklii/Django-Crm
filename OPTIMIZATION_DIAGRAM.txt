BEFORE OPTIMIZATION (Nested Loops with Redundant Calculations):
═══════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────┐
│  for candidate in candidates:                                │
│    ┌───────────────────────────────────────────────────┐   │
│    │  for neighbor in candidate.neighbors:              │   │
│    │    ┌─────────────────────────────────────────┐    │   │
│    │    │  ❌ Calculate neighbor data (SLOW!)     │    │   │
│    │    │     - Filter data                        │    │   │
│    │    │     - Process dates                      │    │   │
│    │    │     - Calculate categories               │    │   │
│    │    │     - Compute VoLL                       │    │   │
│    │    └─────────────────────────────────────────┘    │   │
│    │    ┌─────────────────────────────────────────┐    │   │
│    │    │  Compare candidate with neighbor         │    │   │
│    │    └─────────────────────────────────────────┘    │   │
│    └───────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘

Example with 3 candidates sharing 2 neighbors:
  Candidate A → [Neighbor X, Neighbor Y]
  Candidate B → [Neighbor X, Neighbor Y]  
  Candidate C → [Neighbor X, Neighbor Y]

Total calculations: 6 neighbor calculations
  - Neighbor X calculated 3 times ❌
  - Neighbor Y calculated 3 times ❌


AFTER OPTIMIZATION (Pre-compute + Cache):
═════════════════════════════════════════

Phase 1: PRE-COMPUTATION (One-time)
┌─────────────────────────────────────────────────────────────┐
│  unique_neighbors = get_unique_neighbors()                   │
│  neighbor_cache = {}                                         │
│                                                              │
│  for neighbor_id in unique_neighbors:                        │
│    ┌─────────────────────────────────────────┐             │
│    │  ✅ Calculate neighbor data (once!)     │             │
│    │     - Filter data                        │             │
│    │     - Process dates                      │             │
│    │     - Calculate categories               │             │
│    │     - Compute VoLL                       │             │
│    └─────────────────────────────────────────┘             │
│    neighbor_cache[neighbor_id] = result                      │
└─────────────────────────────────────────────────────────────┘

Phase 2: CANDIDATE PROCESSING (Reuse cache)
┌─────────────────────────────────────────────────────────────┐
│  for candidate in candidates:                                │
│    ┌───────────────────────────────────────────────────┐   │
│    │  for neighbor in candidate.neighbors:              │   │
│    │    ┌─────────────────────────────────────────┐    │   │
│    │    │  ⚡ Get from cache (FAST!)              │    │   │
│    │    │     neighbor_data = cache[neighbor_id]  │    │   │
│    │    └─────────────────────────────────────────┘    │   │
│    │    ┌─────────────────────────────────────────┐    │   │
│    │    │  Compare candidate with neighbor         │    │   │
│    │    └─────────────────────────────────────────┘    │   │
│    └───────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘

Same example with optimization:
  Pre-compute Phase:
    - Neighbor X calculated 1 time ✅
    - Neighbor Y calculated 1 time ✅
  
  Processing Phase:
    - Candidate A → [lookup X, lookup Y] ⚡
    - Candidate B → [lookup X, lookup Y] ⚡
    - Candidate C → [lookup X, lookup Y] ⚡

Total calculations: 2 neighbor calculations
Improvement: 6 → 2 = 66.7% reduction 🚀
